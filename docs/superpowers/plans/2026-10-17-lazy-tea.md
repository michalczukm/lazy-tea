# lazy-tea Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Zbudować zatwierdzoną Kuchenną ściągę z przelicznikiem i minutnikiem.
**Architecture:** Statyczny public/ z HTML, CSS i dwoma modułami JS.
Logika dawki i jeden minutnik nie zależą od DOM.
**Tech Stack:** HTML, CSS, JavaScript, node:test, pnpm, Cloudflare Pages.
**Spec:** docs/superpowers/specs/2026-10-17-lazy-tea-design.md

## Global Constraints

- Polska treść z PRODUCT.md, sześć herbat, dawka 1 g / 100 ml.
- Bez frameworka, bundlera i zależności uruchomieniowych.
- Tablet 1024 × 768 poziomo: podstawowe parametry na jednym ekranie.
- Dźwięk Web Audio API i Gotowe, bez gwarancji alarmu przy blokadzie.
- Publikować tylko public/; bez sekretów i dokumentacji projektowej.

## Review Focus

- Pusta objętość nie pokazuje pozornie poprawnych gramów.
- Zmiana herbaty nie kasuje aktywnego minutnika.
- Uśpione interwały nie przedłużają czasu ani nie powtarzają alarmów.
- Odmowa audio nie blokuje startu i komunikatu końca.
- Polski tekst i edycja mieszczą się na 320 px i przy powiększeniu.
